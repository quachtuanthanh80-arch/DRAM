# Formal Verification Suite for Q-Shield Memory Controller

This directory contains the formal property specifications, SystemVerilog Assertions (SVA), and SymbiYosys (`sby`) proof configurations for the **Q-Shield** secure memory controller. Verification is conducted using **SymbiYosys (SBY)** with the **Z3 SMT solver** (alongside Boolector and Yices2 support) to verify safety invariants, deadlock freedom, and security bounds.

## 🛠️ 2. Formal Methodology

### Tool Versions & Engines
- **SymbiYosys (SBY)**: v0.46+ (YosysHQ Formal Verification Suite)
- **Z3 SMT Solver**: v4.12.2+ (Primary decision procedure for QF_ABV)
- **Boolector / Bitwuzla**: v3.2.1+ (Secondary bit-level decision procedure)
- **Engine Selection**: `smtbmc` engine configured for BMC and $k$-induction.

### BMC vs. Temporal $k$-Induction
- **Bounded Model Checking (BMC, $k \in [20, 25]$)**: Explores state trajectories from initial reset states up to $k$ cycles. Confirms no counter-example exists within the bounded horizon, but does not provide an unbounded mathematical proof.
- **Temporal Induction ($k$-Induction, Prove Mode, $k=30$)**: Proves that if an invariant holds for $k$ consecutive arbitrary states, it must hold for state $k+1$. This establishes unbounded correctness ($\forall t \ge 0$) without requiring state enumeration.

### Input Constraints & Universal Quantification
In SBY, input command streams (`i_cmd_valid`, `i_cmd_row`, `i_cmd_bank`, `i_cmd_bg`) have **NO artificial `assume()` restrictions**. Consequently, the SMT solver proves assertions across all mathematically possible input combinations without artificial constraints.

## 🔍 3. Property Definitions (SVA Assertions)

```systemverilog
// P1: Counter Monotonicity Invariant (sdc_resilient_filter.sv)
always @(posedge clk) begin
    if (!reset && i_cmd_valid && (i_cmd_row == TRACKED_ROW))
        assert (current_count >= past_count);
end

// P2: Single-Cycle Epoch Reset Invariant (sdc_resilient_filter.sv)
always @(posedge clk) begin
    if (reset_epoch_req)
        assert (##1 current_count == 0);
end

// P3: Zero False-Negative Bound (sdc_resilient_filter.sv)
always @(posedge clk) begin
    if (actual_activations >= THRESHOLD)
        assert (mitigation_alert_asserted);
end

// P7: ATE Clamping Bound (adaptive_threshold_engine.sv)
always @(posedge clk) begin
    assert (dyn_threshold >= N_BASE && dyn_threshold <= N_MAX);
end

// P11: Skid Buffer Zero-Drop Invariance (axi4_skid_buffer.sv)
always @(posedge clk) begin
    if (i_valid && !o_ready)
        assert (skid_buffer_occupied && !data_corrupted);
end
```

## ⚠️ 4. Known Limitations

- **Model Level**: Cycle-accurate RTL simulation model (not post-layout gate-level netlist with parasitics).
- **Timing Abstraction**: Does not model analog crosstalk, thermal effects, voltage droop, or semiconductor wear-out/aging.
- **Protocol Assumptions**: Assumes valid JEDEC clocking and reset sequence upon power-up.
- **Quantization**: Fixed-point arithmetic; dynamic thresholds are integer clamped.
- **Attack Assumptions**: Does not model quantum cryptanalytic attacks or side-channel physical probing (DPA/EMA).
